# 🧠 GRPO-Reasoning-Engine: DeepSeek-R1 Style RLVR from Scratch

An open-source, pure PyTorch implementation of **Group Relative Policy Optimization (GRPO)** for Reinforcement Learning with Verifiable Rewards (RLVR). 

This project implements the foundational training loop behind **DeepSeek-R1** from scratch—without relying on high-level RL frameworks (like Hugging Face `trl` or Ray RLlib)—to train a small base model (0.5B–1.5B parameters) to perform chain-of-thought mathematical reasoning on zero budget ($0 compute cost).

---

## 🔬 What We Are Researching

Standard Large Language Models (LLMs) trained via Next-Token Prediction or Supervised Fine-Tuning (SFT) often struggle with multi-step logical deduction, error correction, and long-form math. 

DeepSeek-R1 demonstrated a key breakthrough: **LLMs can spontaneously develop "reasoning" capabilities (like self-correction and reflection) purely through Reinforcement Learning**, provided two conditions are met:
1. **Verifiable Rewards:** The system can deterministically verify if the model's final answer is mathematically correct.
2. **Critic-Free Advantage Estimation (GRPO):** Instead of training a separate, massive "Critic" model to predict reward scores (like standard PPO), the algorithm samples a group of candidate responses for a single prompt and grades each response relative to its group average.

### The Core Problem PPO Had
Traditional **Proximal Policy Optimization (PPO)** requires holding four models in VRAM simultaneously:
* **Actor Model** (The policy being trained)
* **Reference Model** (Frozen original model for KL penalty)
* **Critic Model** (Trained value function estimating expected reward)
* **Reward Model** (Scoring model)

This requires massive GPU clusters ($8\times\text{A100}$ GPUs). 

### How GRPO Solves It
**GRPO eliminates the Critic model entirely.** For a given math prompt, the model generates $G$ independent completions (e.g., $G = 4$ or $8$). We calculate the mean ($\mu$) and standard deviation ($\sigma$) of the group's rewards and compute each candidate's advantage relative to its peers:

$$A_i = \frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r}) + \epsilon}$$

If a candidate completion scores higher than the group average, its likelihood is reinforced. If it performs worse than its peers, it is penalized.

## 🏗️ What We Are Building

We are writing a pure, lightweight PyTorch training engine (`grpo_engine.py`) containing:

1. **Deterministic Rule-Based Verifier:** A regex parser that checks if an extracted solution inside LaTeX tags (e.g., `\boxed{42}`) matches the ground-truth answer (+1.0 for correct, 0.0 for incorrect).
2. **Group Sampling Module:** Generating $G$ completions per prompt using batch forward passes.
3. **Clipped Surrogate Loss Kernel:** Writing the GRPO policy update objective directly in PyTorch tensors.
4. **Unbiased Per-Token KL Divergence Penalty:** Calculating token-level KL divergence against a frozen reference model to prevent policy drift and reward hacking.
5. **Real-time Metrics Tracking:** Plotting token generation length growth (the "aha moment" where reasoning chains lengthen) and math accuracy progression over time.

## 📐 Mathematical Formulation

The objective function optimized in each step is:

$$\mathcal{L}_{\text{GRPO}}(\theta) = -\frac{1}{G} \sum_{i=1}^{G} \left( \min \left( \frac{\pi_\theta(y_i|x)}{\pi_{\theta_{\text{old}}}(y_i|x)} A_i, \text{clip}\left(\frac{\pi_\theta(y_i|x)}{\pi_{\theta_{\text{old}}}(y_i|x)}, 1-\epsilon, 1+\epsilon\right) A_i \right) - \beta D_{\text{KL}}(\pi_\theta \parallel \pi_{\text{ref}}) \right)$$

Where:
* $x$ is the math prompt.
* $y_i$ is the $i$-th generated completion in the sampled group.
* $A_i$ is the group-normalized advantage score.
* $\epsilon$ is the clipping hyperparameter (typically $0.2$).
* $\beta$ controls the strength of the KL divergence penalty against policy collapse.
